# Сборка 

Если Вы решили вручную поддерживать Wex, то вот инструкция:
- обязательно использовать `nodejs 18`, не старше.
- после установки, пишем `npm i` и `npm run build`

# npm-модуль отвалился!

На случай если хоть один npm-модуль отвалился и руинит всю сборку, 
мы специально подготовили упакованный rar-архив со всеми модулями 
которые работают ТОЧНО и спокойно компилируют проект. Найти их 
можно в корневом файле `node_modules.rar`
