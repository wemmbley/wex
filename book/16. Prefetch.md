# Префетч

Префетч нужен для оптимизации скорости загрузки сайта для UX клиента. 
При наведении мышкой с ПК все данные предзагружаются в стейт.

Пример можете найти по пути: `/demo/Prefetch/`. В этой папке цельно всё показано.

## Декларативный пример
```html 
<template id="app">
    <button id="btn-load">Загрузить список</button>
</template>

<script>
  $('#app').state({items: []}).mount();
</script>
```

## Императивный пример:
```html 
<template id="app">
  <button w-prefetch="https://mysite.loc/data.json" w-to="items">
    Получить данные при наведении и тут же записать их в стейт.
  </button>
</template>

<script>
  $('#app')
      .state({items: []})
      .on('mouseenter', '#btn-load', () => {
          // Делаем префетч при наведении
          $wire.prefetch('./LazyItems.json')
      })
      .on('click', '#btn-load', (state) => {
          // А вот при клике уже загружаем в стейт
          $wire.get('./LazyItems.json').to(state.items)
      })    
      .mount();
</script>
```
